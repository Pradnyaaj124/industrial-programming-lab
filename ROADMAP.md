# Learning Curriculum & Progression Roadmap

This roadmap outlines the complete learning sequence of the **Logic Building with Industrial Project Development** batch. The journey moves systematically from foundational logic and systems memory up to enterprise Java, concurrency, and Low-Level Design (LLD).

---

## Phase Progression

### Phase 1: Logic Building
- **Status**: Not Started
- **Focus**: Algorithmic thinking and basic computational logic.
- **Key Concepts**:
  - Decision making (`if`, `if-else`, `nested-if`, `switch-case`)
  - Iteration loops (`for`, `while`, `do-while`, nested loops)
  - Number theory & mathematical problem solving (digits, factors, primes, series)
  - Pattern printing and spatial logic
  - Menu-driven architectures and validation logic

---

### Phase 2: Arrays and Matrices
- **Status**: Not Started
- **Focus**: Contiguous memory organization and linear data handling.
- **Key Concepts**:
  - 1D array traversal, insertion, and deletion
  - Two-pointer techniques and window scanning
  - Array filtering, reversals, and sub-array logic
  - 2D arrays & matrix arithmetic (transposition, rotation, multiplication)
  - Matrix traversals (spiral, diagonal, boundary)

---

### Phase 3: Strings
- **Status**: Not Started
- **Focus**: Character sequences, memory layouts, and textual parsing.
- **Key Concepts**:
  - Null-terminated character arrays in C
  - String manipulation functions without library dependencies
  - String case conversion, trimming, and word counting
  - Palindrome checking and anagram detection
  - Substring searching and tokenization
  - Immutable Strings vs mutable buffers in Java (`StringBuilder`, `StringBuffer`)

---

### Phase 4: Bit Manipulation
- **Status**: Not Started
- **Focus**: Low-level hardware-aligned operations and bitwise arithmetic.
- **Key Concepts**:
  - Bitwise operators: AND (`&`), OR (`|`), XOR (`^`), NOT (`~`), shifts (`<<`, `>>`, `>>>`)
  - Bit masks: creating dynamic masks for testing and toggling bits
  - Setting, clearing, and toggling specific bit positions
  - Counting set bits (Brian Kernighan’s algorithm, lookup tables)
  - Power of two checks, parity calculation, and bitwise tricks

---

### Phase 5: Memory Management
- **Status**: Not Started
- **Focus**: Systems-level memory architecture and dynamic allocation.
- **Key Concepts**:
  - Variable addresses, pointer declaration, and dereferencing
  - Pointer arithmetic and relationship with arrays
  - Double pointers (pointer-to-pointer) and indirect addressing
  - Heap allocation via `malloc`, `calloc`, `realloc`, and `free`
  - Memory leak detection, dangling pointers, and wild pointers
  - Void pointers, function pointers, and callback mechanics

---

### Phase 6: Structures and Generic Programming
- **Status**: Not Started
- **Focus**: Composite types, memory alignment, and generic paradigms.
- **Key Concepts**:
  - C structures, member access, memory padding, and alignment
  - Unions and memory sharing
  - Self-referential structures (foundations of nodes)
  - `typedef` for type abstraction
  - C++ function and class templates (`template <typename T>`)
  - Type-independent algorithms and data containers

---

### Phase 7: Recursion
- **Status**: Not Started
- **Focus**: Call-stack execution, recurrence relations, and base cases.
- **Key Concepts**:
  - Call-stack mechanics and activation records
  - Base conditions and termination guarantees
  - Head recursion vs tail recursion (tail call optimization)
  - Recursive mathematical series (factorial, fibonacci, gcd)
  - Tree-like recursive branch decomposition and backtracking foundations

---

### Phase 8: Data Structure Implementation
- **Status**: Not Started
- **Focus**: Building core data structures completely from scratch.
- **Key Concepts**:
  - Singly Linked List (creation, traversal, insert, delete, reverse)
  - Doubly Linked List and Circular Linked List
  - Stack implementation (array-based and linked-list-based)
  - Queue & Circular Queue implementation
  - Deque (Double Ended Queue) implementation
  - Binary Trees, Binary Search Trees (BST), and tree traversals

---

### Phase 9: Searching and Sorting
- **Status**: Not Started
- **Focus**: Fundamental search heuristics and sorting mechanics.
- **Key Concepts**:
  - Linear Search and Binary Search
  - Comparison sorts: Bubble Sort, Selection Sort, Insertion Sort
  - Divide-and-conquer sorts: Merge Sort, Quick Sort
  - Non-comparison sorts: Counting Sort
  - Time and space complexity trade-offs

---

### Phase 10: Core Java
- **Status**: Not Started
- **Focus**: Java Virtual Machine (JVM) architecture and core syntax.
- **Key Concepts**:
  - Class definitions, object instantiation, and JVM memory areas (Heap, Stack, Metaspace)
  - Constructor types (default, parameterized, copy) and constructor chaining
  - Static members, static blocks, and initialization order
  - Access specifiers and package structure
  - Exception handling (`try`, `catch`, `finally`, `throw`, `throws`, custom exceptions)
  - Abstract classes and interfaces (including default/static methods)
  - Java Standard Library utilities and I/O streams

---

### Phase 11: Java Collections
- **Status**: Not Started
- **Focus**: Standard enterprise collection framework and generic algorithms.
- **Key Concepts**:
  - `Collection` hierarchy (`List`, `Set`, `Queue`)
  - `ArrayList` vs `LinkedList` internals
  - `HashSet`, `LinkedHashSet`, and `TreeSet` (Hashing vs Red-Black Trees)
  - `HashMap`, `LinkedHashMap`, and `TreeMap` internals
  - `PriorityQueue` and `ArrayDeque`
  - Iterators, `ListIterator`, and `Spliterator`
  - Sorting with `Comparable` and `Comparator`

---

### Phase 12: File and System Programming
- **Status**: Not Started
- **Focus**: Persistent storage, OS interaction, and low-level streams.
- **Key Concepts**:
  - File descriptors, opening, reading, writing, and closing files
  - Byte streams vs character streams
  - Binary file I/O and object serialization (`Serializable`, `transient`)
  - System calls, environment variables, and process execution
  - Command-line arguments parsing and CLI utility development

---

### Phase 13: Network Programming
- **Status**: Not Started
- **Focus**: Sockets, protocols, and client-server communication.
- **Key Concepts**:
  - Socket programming fundamentals
  - Transmission Control Protocol (TCP) client-server architecture
  - User Datagram Protocol (UDP) datagram sockets
  - Custom communication protocols and payload serialization
  - Multi-client handling using concurrency

---

### Phase 14: Multithreading
- **Status**: Not Started
- **Focus**: Concurrency, synchronization, and parallel execution.
- **Key Concepts**:
  - Thread creation (`Thread` class and `Runnable` interface)
  - Thread lifecycle and state transitions
  - Race conditions and critical sections
  - Synchronization (`synchronized` methods, synchronized blocks)
  - Inter-thread communication (`wait()`, `notify()`, `notifyAll()`)
  - Locks, `ReentrantLock`, and condition variables
  - Thread pools and Executor Framework (`ExecutorService`)

---

### Phase 15: Object-Oriented Design
- **Status**: Not Started
- **Focus**: Software design principles, modularity, and clean architecture.
- **Key Concepts**:
  - Four pillars: Encapsulation, Abstraction, Inheritance, Polymorphism
  - Association, Aggregation, and Composition
  - Coupling and Cohesion metrics
  - SOLID Principles:
    - Single Responsibility Principle (SRP)
    - Open/Closed Principle (OCP)
    - Liskov Substitution Principle (LSP)
    - Interface Segregation Principle (ISP)
    - Dependency Inversion Principle (DIP)
  - Object-oriented problem decomposition and class modeling

---

### Phase 16: Design Patterns and LLD
- **Status**: Not Started
- **Focus**: Gang of Four (GoF) patterns and enterprise Low-Level Design.
- **Key Concepts**:
  - Creational Patterns: Singleton, Factory, Abstract Factory, Builder, Prototype
  - Structural Patterns: Adapter, Decorator, Facade, Composite, Proxy
  - Behavioral Patterns: Observer, Strategy, Command, State, Template Method
  - Low-Level Design (LLD) modeling and UML diagramming
  - Industrial system decomposition (e.g., Parking Lot, Elevator System, Vending Machine)
