# Industrial Programming Lab

> A structured collection of programming implementations focused on problem solving, data structures, systems programming, Java development, object-oriented design, networking, multithreading, and low-level design.

This repository contains structured programming implementations developed while strengthening software engineering and computer science fundamentals. It serves as a practical codebase demonstrating progressive progression from core computational logic and low-level memory mechanics up to enterprise Java, concurrent architectures, and object-oriented system modeling.

---

## Technical Focus

The repository covers core competencies across software engineering and system development:

- **Programming Fundamentals & Logic Building**: Decision branching, iteration patterns, and mathematical problem decomposition.
- **Arrays & Matrices**: Memory layouts, multi-dimensional array traversal, filtering, and matrix transformations.
- **Strings**: Character sequence handling, custom string manipulations, and textual parsing.
- **Bit Manipulation**: Bitwise operations, bit masking strategies, and binary arithmetic.
- **Memory Management**: Dynamic memory allocation (`malloc`, `free`), pointer mechanics, and memory layout inspection in C.
- **Structures & Generic Programming**: Composite types, memory alignment, and C++ template abstractions.
- **Recursion**: Call-stack execution mechanics, base conditions, and recursive problem decomposition.
- **Data Structure Implementation**: Implementing fundamental data structures (Linked Lists, Stacks, Queues, Trees) from scratch.
- **Searching & Sorting**: Standard search heuristics and comparison/non-comparison sorting algorithms.
- **Core Java**: JVM runtime model, object lifecycle, access modifiers, packages, and exception handling.
- **Java Collections**: Detailed exploration of lists, sets, maps, queues, iterators, and custom comparator sorting.
- **File & System Programming**: Byte and character streams, file descriptors, serialization, and operating system interaction.
- **Network Programming**: Client-server socket communication over TCP and UDP protocols.
- **Multithreading**: Thread lifecycles, synchronization, race conditions, locks, and thread pools.
- **Object-Oriented Design**: Clean class responsibilities, SOLID design principles, and decoupling techniques.
- **Design Patterns & Low-Level Design (LLD)**: Creational, structural, and behavioral patterns applied to system modeling.

## Approach

The repository follows a structured engineering progression:

$$\text{Fundamentals} \longrightarrow \text{Implementation} \longrightarrow \text{Data Structures} \longrightarrow \text{Systems Programming} \longrightarrow \text{Java} \longrightarrow \text{Concurrency \& Networking} \longrightarrow \text{OOP Design} \longrightarrow \text{Design Patterns \& LLD}$$

The emphasis is on writing implementations from the ground up, understanding underlying memory and runtime behavior, and gradually moving toward larger modular software design problems.

## Featured Technical Work

Key architectural implementations and system focus areas covered across this repository include:

- **From-Scratch Data Structures**: Core linear and non-linear data structures implemented without reliance on standard library abstractions.
- **Systems & File Programming**: Low-level file manipulation, byte-stream utilities, and custom virtual file system concepts.
- **Concurrent & Networked Services**: Multi-threaded socket servers demonstrating thread coordination, resource synchronization, and TCP/UDP communication.
- **Object-Oriented & Low-Level Design (LLD)**: GoF design pattern implementations and structural modeling for real-world scenarios (such as parking lot systems and resource allocators).

*(Note: Standalone, multi-tier software projects developed outside this lab are maintained in dedicated repositories.)*
